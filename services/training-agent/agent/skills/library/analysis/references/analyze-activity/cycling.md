# 骑行证据与判断

- 先区分户外、室内和虚拟骑行，再说明本次时长、强度分布和主要训练刺激。虚拟骑行区分路线坡度、坡度模拟与 ERG 目标功率，实际阻力结合骑行台模式和记录说明。
- 功率有效且阈值已知时才解释 NP、IF、TSS；注明阈值依据。Garmin training_load_peak 和 Training Effect 是另一套指标，不能替换 TSS。
- 全窗口平均包括真实零功率；非零平均只描述踩踏阶段。缺测不能填成零，短时峰值不能当成持续能力。
- 冲刺、间歇和爬坡先使用已有候选；明确时间或距离问题必须取得对应原始窗口。结合功率、持续时间、踏频、心率和地形，不凭单个峰值下结论。
- 单次活动可以描述表现，不能直接证明 FTP 提升、过度训练或长期恢复状态。没有功率时使用时长、心率与主观感受，并明确精度限制。
- 输出顺序：本次判断 → 支撑数据与窗口 → 数据缺口 → 一项可执行建议。工具数值与单位保持原样，不把不同平均口径混用。
