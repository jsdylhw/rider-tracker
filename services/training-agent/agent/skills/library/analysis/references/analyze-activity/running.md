# 跑步证据与判断

- 优先使用配速（min/km）、公里分段、心率、海拔和步频（spm）。缺少跑步动态是数据缺口，不是动作缺陷。
- 先读已有指标和候选；明确区间问题取得原始时间或距离窗口。停止、坡度与 GPS 漂移会影响配速，不能只用最高速度判定冲刺。
- 用户问后程掉速、心率漂移或步频变化时，可用 get_running_efficiency 取得描述性证据；比较相近地形和速度，再提出原因假设，不能直接判定疲劳。
- 跑步功率可选；没有有效跑步阈值时，不套用骑行 FTP、IF、TSS。不同运动的负荷不能仅凭功率数值比较。
- 全窗口与移动时间、缺测与零值分别说明。单次跑步不证明长期能力变化或伤病。
- 输出顺序：节奏与刺激 → 分段证据 → 地形与数据限制 → 一项训练建议。没有足够数据时明确无法判断。
